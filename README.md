# Sneha Sajeev — Portfolio

A premium single-page React/Vite portfolio built from the supplied resume content and portrait.

## Run locally

```bash
npm install
npm run dev
```

Then open the local Vite URL shown in the terminal.

## Build

```bash
npm run build
npm run preview
```

## Notes

- Content is limited to information present in the supplied resume.
- The supplied portrait is included as `public/sne.jpg`.
- No projects, testimonials, social profiles, metrics, or achievements were invented.
- The design takes inspiration from the supplied sample description, while adapting the content to Sneha's actual experience.
